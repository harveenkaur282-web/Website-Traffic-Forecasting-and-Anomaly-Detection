# Website-Traffic-Forecasting-and-Anomaly-Detection
End-to-end time series project: forecasting daily website traffic (Wikipedia pageviews) with SARIMA, Prophet and LightGBM, detecting anomalies, and serving results in a Streamlit dashboard.

## Abstract
web traffic is the amount of data that is sent and received by visitors to a website, and it has been the largest portion of internet traffic.
